# RC-Motor
This project allows to build radio controlled vehicles with a generic base set of two Arduino controllers. One drives the vehicle, the other is used as radio control logic. The radio control logic is optional, the vehicle can also be controled by local controls.

# Project development
The project was designed using https://app.cirkitdesigner.com/. It is intended to be developed there and this repository serves as a backup and history, as the app doesn't provide any versioning.

Find the project under this link:
https://app.cirkitdesigner.com/project/439c4bb6-223c-4504-a517-f85c164abab8

# Contribute
To contribute:
* Access the project on cirkitdesigner.com
* Make your changes and save it as a local copy
* Transfer your changes to the repository:
  * Copy the code and update in the repository files
  * Export the file as image with default settings and store in this folder 
  * Export the file as cirkit file (*.ckt), name it "export" and replace the file in this folder
* Create pull request with your changes
